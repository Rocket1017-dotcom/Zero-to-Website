My Personal Roadmap

Documenting my transition from practicing raw keys on a home row typing test to managing multi-page web directory networks.

Week 1

Keyboard Mastery & Curiosity

Started on Typing.com to increase computer speed. Realized the upper rows of characters (braces, brackets, F-keys) had a hidden purpose in tech, sparking my front-end coding journey.

Week 2

The HTML & CSS Foundation

Coded structural page frames (HTML) and styled a modern dark-mode aesthetic (CSS). Connected interactive JavaScript event listeners for live browser triggers.

Week 3

Multi-Page Architecture & Real-Time Search

Upgraded Zero To Website into a connected multi-page setup (`index.html`, `journey.html`, `tools.html`). Built dynamic search filtering logic and custom UX fallback components.

Week 4

Deployment & Going Live

Transitioned from local browser previews (`vscode.dev`) to publishing live code onto global web hosting servers accessible to the public.

Week 5 (Current)

The Shift to Directed Engineering

Realized that success in modern web development isn't about memorizing every line of syntax or terminal command—it's about directing AI co-pilots effectively to turn ideas into live web assets in record time.
